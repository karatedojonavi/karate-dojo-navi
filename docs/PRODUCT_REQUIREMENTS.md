# 製品要件定義書(PRODUCT_REQUIREMENTS)

## 1. ターゲットユーザー

| ユーザー | 主なニーズ |
|---|---|
| 子どもの習い事を探す保護者(30〜40代、スマホ利用) | 近所の道場・曜日・月謝・雰囲気を知りたい |
| 転居先で道場を探す経験者 | 同じ流派・会派の道場を探したい |
| 初めて空手を始めたい成人/再開したい人 | 大人が通える道場か知りたい |
| 形や組手を本格的に学びたい競技者 | 大会実績・活動内容を知りたい |
| 道場運営者・指導者 | 無料で道場を知ってもらいたい。登録は簡単がいい |

## 2. サイトマップ

```

/search                     検索結果一覧
/dojos/[id]                 道場詳細

/admin/*                    管理者画面(要ログイン・管理者権限)
```

## 3. 画面一覧と詳細要件

### 3-1. トップページ(/)

構成(上から順に):

1. **ファーストビュー**: キャッチコピー+検索フォーム(都道府県セレクト+市区町村セレクト+検索ボタン)。1タップ目で地域検索に入れること
2. **こだわり検索への導線**: 曜日・月会費・流派で絞るリンク
3. **空手を習う魅力**(保護者向けセクション)
4. **初めての方へ**(伝統空手とフルコンタクト空手の基本的な違い、道場を探す流れ)
5. **地域から探す**(47都道府県リンク。道場が存在する県を上位・強調表示)
6. **道場運営者の方へ**(無料掲載案内への導線)
7. **運営理念**(要約+/aboutへのリンク)
8. **よくある質問**(3〜5件+/faqへのリンク)
9. **フッター**(法務ページリンク、全空連公式ではない旨の注記)

#### キャッチコピー案(実装時はAを採用、A/Bは後から差し替え可能に)

- 案A: 「礼にはじまり、自信にかわる。— 近くの空手道場が見つかる」
- 案B: 「はじめての空手、はじめての道場えらび。」
- 案C: 「その子に合う道場が、きっと近くにある。」

補足コピー案:
「全日本空手道連盟系の道場・空手教室を、地域・曜日・月会費・流派からかんたん検索。体験・見学の申込みまでこのサイトで。」

#### 「空手を習う魅力」セクション原稿(そのまま使用可)

見出し: 空手で育つ、心とからだ。

- **礼儀と挨拶が身につく** — 稽古は礼に始まり礼に終わります。挨拶、相手を尊重する姿勢、年長者を敬う心を、日々の稽古の中で自然に学びます。
- **心身の健やかな成長** — 形(かた)と組手(くみて)の両方に取り組み、柔軟性・体幹・集中力・忍耐力をバランスよく育てます。
- **仲間と居場所ができる** — 先輩が後輩を支える文化の中で、学校とは別の仲間と安心できる居場所が得られます。
- **男女問わず、幼児から大人まで** — 多くの道場が幼児から成人まで受け入れており、大人になってから始める人・再開する人も少なくありません。
- **続けやすい習い事** — 屋内での稽古が中心で天候に左右されにくく、道具の消耗も比較的少なめ。保護者当番や遠征が少ない道場もあります。
- **目標を持って続けられる** — 全空連公認段位の取得を目標にできます。長く努力を続けた実績のひとつとして、履歴書などに記載する人もいます。

注意書き(セクション末尾に小さく表示):
「費用・安全対策・保護者の関わり方は道場ごとに異なります。見学・体験の際に各道場へご確認ください。」

#### 「伝統空手とフルコンタクト空手」説明原稿

「空手にはいくつかの系統があります。当サイトが扱うのは、全日本空手道連盟(全空連)系の道場です。全空連系の空手は『伝統空手』と呼ばれることが多く、形(かた)の演武と、寸止めを基本とした組手競技を行います。オリンピック競技として採用された空手もこの系統です。一方、直接打撃を行う『フルコンタクト空手』(極真空手など)は別の系統であり、当サイトの掲載対象外です。どちらも素晴らしい空手ですが、当サイトでは運営者自身が歩んできた全空連系の道場をご紹介しています。」

### 3-2. 検索結果一覧(/search)

- 検索条件: 都道府県(必須ではない)、市区町村、稽古曜日(複数可)、月会費範囲(下限・上限のセレクト: 〜3,000円/〜5,000円/〜8,000円/8,000円超 等の区分)、流派(複数可)、キーワード(道場名・ふりがな・紹介文を対象)
- 任意の絞込みチェックボックス: 「初心者歓迎の記載あり」「パラ空手・障害者対応あり」(登録データがboolean+自由記述で軽量なため、MVPに含める)
- 結果カード表示項目: 写真(未登録時は共通画像)、道場名、市区町村、流派バッジ、稽古曜日、月会費(「3,000〜5,000円/月」形式)、体験受付方法アイコン
- 並び順(スコア降順): ①市区町村完全一致 > 都道府県一致 ②情報充実度(紹介文・写真・稽古場所・費用の登録有無を加点) ③情報更新日の新しさ ④同点時は道場名の五十音順。料金による優先表示はMVPでは行わない
- ページネーション(20件/ページ)
- 該当0件時: 条件を緩めた提案(「○○県全体で探す」)を表示

### 3-3. 道場詳細(/dojos/[id])

表示セクション順:

1. 道場名・ふりがな・流派・市区町村・写真
2. **体験・見学の申込み**(最重要CTA。設定された受付方法をボタンで並べる: サイト内フォーム/電話(タップ発信)/メール/LINE/公式HP/外部フォーム。「現在は受付停止中」の場合はその旨表示)
3. 道場紹介文・生徒募集に関する記述
4. **稽古場所と曜日・時間**(場所ごとにカード表示: 場所名・住所・Googleマップリンク・駐車場補足・その場所の曜日/開始/終了/クラス補足。週間一覧表も表示: 曜日×場所×時間のマトリクス)
5. 費用(月会費 最低額〜最高額+補足。注意書き: 「入会時に必要な費用、スポーツ保険、登録料、道着・防具代、審査料、大会参加費等については、見学・体験時に各道場へご確認ください。」)
6. 対象者(自由記述または選択項目: 幼児から成人まで/小学生以上/成人も参加可能/親子で参加可能)・パラ空手/障害者対応の有無と補足
7. 代表者・指導者紹介(代表者氏名、全空連公認段位、都道府県連盟等の段位、その他段位補足、紹介自由記述)
8. 活動内容・指導方針、初心者受入れ、大会参加、道場の主な大会実績
9. 所属(流派・会派/団体。注釈: 「所属会派により参加できる大会が異なる場合があります。詳しくは各道場にご確認ください。」)
10. リンク(公式HP・Instagram・Facebook・X・LINE・その他)
11. 電話受付情報(番号・受付曜日・時間・担当窓口・補足・「稽古中は電話に出られない場合があります」)
12. 免責注記: 「掲載されている所属情報は、原則として各道場からの申告または公開情報に基づいています。当サイトが所属関係を保証するものではありません。」

### 3-4. 体験・見学申込みフォーム(/dojos/[id]/apply)

入力項目(これ以上増やさない):

- 申込者氏名(必須)
- 参加する人の年代または学年(必須。セレクト: 未就学児/小学1-3年/小学4-6年/中学生/高校生/成人)
- 未成年または成人(年代から自動判定し、未成年の場合「保護者の方がお申し込みください」を表示)
- メールアドレス(必須・形式検証)
- 電話番号(必須)
- 希望日(任意・カレンダー入力+「相談したい」チェック)
- 見学または体験(必須・ラジオ)
- 空手経験の有無(必須・ラジオ: なし/経験あり)
- 質問・連絡事項(任意・テキストエリア)
- 個人情報の取扱いへの同意(必須チェック・プライバシーポリシーへのリンク)

送信時の動作: ①DBに保存 ②道場の登録メールアドレスへ自動通知(Resend) ③申込者へ受付完了の自動返信 ④道場運営者マイページに表示。
安全対策(必須実装): 入力値検証(zod)、CSRF対策、honeypot+送信間隔チェックによるボット対策、IPベースのレート制限、監査ログ。詳細は SECURITY_AND_PRIVACY.md。

### 3-6. 道場運営者マイページ(/owner/*)

- /owner/login, /owner/signup: メール+パスワード認証(Supabase Auth)
- /owner/claim: 道場管理権限の申請(道場を検索→「この道場の情報を管理する」→申請理由・連絡先・道場との関係を入力)
- /owner/dojos: 自分が管理する道場一覧(1アカウントで複数道場を管理可能)
- /owner/dojos/[id]/edit: 道場情報編集(公開項目すべて)。保存で即時反映(承認不要)。編集は監査ログに記録
- /owner/dojos/[id]/locations: 稽古場所の追加・編集・削除(場所ごとに曜日・時間・クラス補足を複数登録)
- /owner/dojos/[id]/applications: 体験・見学申込みの一覧・状態管理(受付済み/対応中/完了/キャンセル/その他)
- /owner/dojos/[id]/stats: 自道場の申込み件数(累計・月別・見学/体験内訳)と電話番号タップ数

### 3-7. 管理者画面(/admin/*)

- ダッシュボード: 全国の道場数・申込み件数・タップ数のサマリー
- 道場管理: 一覧(検索・フィルタ)、登録、編集、公開/非公開、削除、**CSV一括登録**(テンプレート提供・エラー行レポート)、CSVエクスポート、**重複道場の統合**(2件選択→残す方を指定→稽古場所・申込み・タップ記録を付け替え)
- 稽古場所管理: 道場配下で追加・編集・削除
- 管理権限申請の確認: 申請者・申請理由の確認→承認/却下(確認方法メモを残す)。承認者・承認日・確認方法を記録
- 権限管理: 管理権限の付与・取消し、管理者/スタッフ権限の分離(スタッフは削除・権限操作不可)
- 写真の確認・削除・非公開化
- 申込み集計: 全国/都道府県別/市区町村別/道場別、月別推移、見学/体験内訳
- 電話番号タップ数集計(道場別・稽古場所別・月別)
- 更新停滞道場一覧(最終更新から12ヶ月以上経過)
- 通報・修正依頼・削除依頼の対応キュー(状態: 未対応/対応中/完了)
- 監査ログ閲覧(誰が・いつ・何を変更したか)

## 4. 道場データの登録項目

DATABASE_SCHEMA.md のテーブル定義と対応する。**ここに書かれていない入力項目を追加しない。**

### 基本情報
道場名、ふりがな、紹介文、代表者氏名、運営団体名(道場名と異なる場合のみ任意)、都道府県、主な市区町村、電話番号、電話受付可否、電話受付曜日、電話受付時間、電話担当窓口名、電話補足、メールアドレス、公式HP、Instagram、Facebook、X、LINE、その他URL、写真1枚、生徒募集自由記述、公開/非公開、最終更新日(自動)

### 稽古場所(1道場に複数)
場所名、郵便番号、都道府県、市区町村、住所、建物・施設名、緯度・経度(住所からの自動ジオコーディング+管理画面でのピン微調整。運営者が数値を直接入力するUIにしない)、駐車場自由記述、稽古枠(複数): 曜日・開始時刻・終了時刻・対象/クラス補足

### 流派・会派
流派(必須・複数可): 松濤館流/剛柔流/糸東流/和道流/その他(自由入力)。管理者が表記揺れを後から統合できるマスタ方式。
会派・団体(任意・複数可): 日本空手協会/全空連剛柔会/全空連糸東会/全空連和道会/その他(自由入力)

### 活動情報
活動内容・指導方針(自由記述)、初心者受入れ(自由記述+「初心者歓迎」boolean)、大会参加(自由記述)、道場の主な大会実績(自由記述)、パラ空手・障害者対応(boolean+補足)、その他の特徴、対象者(自由記述または簡易選択)

### 指導者・段位
全空連公認段位、都道府県連盟等の段位、その他段位補足、代表者・指導者紹介(自由記述)。
※全空連公認段位と県連等の段位は別項目。段位で優劣判定・並び替えをしない。個別指導者のプロフィール項目は作らない(自由記述欄で対応)

### 費用
月会費最低額(円・整数)、月会費最高額(円・整数)、月会費補足(自由記述。例: 「幼児2,000円、小学生3,000円、一般4,000円」)。入会金等の細目項目は作らない

### 受付方法
体験・見学の受付方法(複数選択): サイト内フォーム/電話/メール/LINE/公式HP/外部フォーム(URL)/受付停止中

### 掲載確認(登録時のチェック項目)
- 「当道場は、全日本空手道連盟系の都道府県連盟、市区町村連盟、会派または関係団体に所属している道場・教室です。」(必須)
- 「掲載する写真について、被写体の掲載権限・肖像権等に関する必要な同意を得ています。」(写真登録時必須)
- 子どもが写る写真は保護者等の同意を得たもののみ掲載する旨の注意書きを表示

## 5. ユーザーフロー

### 保護者が道場を見つけて体験を申し込む
トップ→都道府県・市区町村選択→検索結果→道場詳細→「体験・見学を申し込む」→フォーム送信→完了画面+自動返信メール→道場から連絡が来る

### 道場運営者が自道場を登録・管理する(主要フロー)
アカウント登録→「新しい道場を登録する」→全空連系である旨の確認チェック→情報入力→管理者確認(なりすまし・対象外道場でないかの目視)→公開→以後は自分で編集(即時反映)
※運営側が道場の許可なく事前登録することはしない。掲載は道場主自身の登録による。初期は運営者が知人・県連関係者へ声かけし、/for-dojos(無料掲載案内)へ誘導する
※CSV一括登録は、対面サポート等で**道場の同意を得て代理登録する場合**の管理者用ツールとして残す

### 既存ページの管理権限を引き継ぐ(補助フロー)
道場の代替わり・担当者変更などで、既存の道場ページを別のアカウントが管理したい場合: 道場を検索→「この道場の情報を管理する」→申請理由・道場との関係を入力→管理者が確認(電話・公式SNS等)→承認→編集可能に

### 電話で問い合わせる
道場詳細→電話ボタンタップ(タップイベント記録)→電話アプリ起動

## 6. 電話番号タップ計測

- 記録項目: 道場ID、稽古場所ID(該当する場合)、タップ日時、流入ページ(リファラ)、匿名化セッションID(cookieベース、個人特定情報なし)
- 表示名は必ず「電話番号タップ数」とする(発信・接続・入会は確認できないため)
- 道場運営者は自道場分のみ、管理者は全体を閲覧可能
