# 運用マニュアル(OPERATIONS)

このドキュメントは、プログラミングの知識がない後任者・共同運営者でもサイトを維持できるようにするためのもの。
フェーズ7完了時に、実装内容に合わせてClaude Codeが本ドキュメントを最終化すること(画面キャプチャの代わりに、画面上のボタン名・メニュー名を正確に記載する)。

## 1. サービス全体像

- サイト本体: Vercel(表示・配信)
- データベース・写真・ログイン: Supabase
- メール送信: Resend
- ドメイン: (取得先レジストラ名を記載)
- エラー通知: Sentry(異常があると管理者メールに通知が届く)

## 2. アカウントと認証情報の管理(最重要)

- 上記すべてのサービスのログイン情報は、特定個人のメールアドレスに依存させない
- 推奨: 運営専用のメールアドレス(例: info@ドメイン)を作り、全サービスをこのアドレスで登録。パスワードは共有パスワードマネージャー(または金庫保管の紙)で管理者間共有
- 各サービスに共同管理者を招待できる場合は必ず2人以上を登録する(Vercel Team / Supabase Organization / Resend Team)
- ドメイン・サーバー・DBは**自動更新・自動課金**に設定し、支払いカードの有効期限切れに注意(年1回の確認事項)

## 3. 日常運用(週1回・15分)

1. 管理画面ダッシュボードを開く
2. 「管理権限申請」を確認 → 申請理由と連絡先を見て、道場の代表者本人か確認(電話または道場公式SNS経由での確認を推奨)→ 承認/却下。確認方法をメモ欄に残す
3. 「通報・修正・削除依頼」を確認 → 内容に応じて道場情報を修正、悪質な場合は非公開化
4. 新規登録道場(owner登録分)を確認 → 全空連系でない・なりすましの疑いがあれば非公開化して連絡
5. 写真の確認 → 不適切な写真は非公開化

判断に迷ったら: 非公開化してから調べる(公開したまま放置しない)。

## 4. 月次運用(月1回・15分)

- Vercel / Supabase / Resend の使用量画面を確認(無料枠の8割を超えていたら有料プラン移行を検討。目安コスト: 3サービス合計で月7,000円前後)
- Sentryのエラー一覧をざっと確認(同じエラーが大量に出ていたらClaude Codeに調査を依頼)
- 「更新停滞道場一覧」を確認し、必要なら道場へ更新のお願いを連絡

## 5. よくある対応

### 道場から「掲載をやめたい」と連絡が来た
管理画面 → 該当道場 → 非公開化(データは残る)。完全削除を求められたら削除を実行。

### 道場から「情報を直してほしい」と連絡が来た
その道場に管理権限者がいれば「マイページから編集できます」と案内。いなければ管理画面で代理修正し、あわせて管理権限申請を案内。

### 利用者から「この道場は全空連系ではないのでは」と通報が来た
道場を一旦そのままに、道場側へ確認連絡。回答がない・虚偽と判明した場合は非公開化。

### 申込みメールが道場に届かないと言われた
①道場の登録メールアドレスの誤りを確認 ②迷惑メールフォルダを案内 ③マイページの申込み一覧でも確認できることを案内 ④それでも不明ならSentryとResendの送信ログを確認(Claude Codeに依頼可)。

### サイトが表示されない
①Vercelのステータスページ確認 ②Supabaseのステータスページ確認 ③外部サービス障害なら復旧を待つ(こちらの作業は不要)④それ以外はSentryのエラーを添えてClaude Codeに調査を依頼。

## 6. Claude Codeへの依頼方法(後任者向け)

1. PCでプロジェクトフォルダを開き、ターミナルで `claude` を起動
2. 「CLAUDE.mdとdocs/OPERATIONS.mdを読んでから対応して」と前置きし、起きている問題をそのまま日本語で伝える
3. エラー画面が出ている場合は文言をコピーして貼る
4. 変更を本番に反映する前に「何をどう変えるか」を説明してもらい、納得してから進める

## 7. データの守り方

- データベースはSupabaseが自動バックアップ(復元もSupabase管理画面から可能)
- 加えて週1回、道場データのCSVが自動でストレージに保存される(緊急時の復元素材)
- 体験申込みの個人情報は180日で自動的に匿名化される(手作業不要)
