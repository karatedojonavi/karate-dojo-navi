# セキュリティ・個人情報・法務(SECURITY_AND_PRIVACY)

## 1. セキュリティ要件(必須実装)

### フォーム・入力
- 全入力をzodスキーマでサーバー側検証(クライアント検証は補助)
- Server Actions利用によりCSRFはNext.jsの仕組みで防御。独自fetchのAPI(phone-tap)はSameSite cookieとOriginチェック
- 体験申込みフォーム: honeypotフィールド+表示から送信までの最短時間チェック(2秒未満は拒否)によるボット対策
- レート制限: 申込みは同一IPから10分に3件まで、phone-tapは同一セッションから同一道場へ1分に5件まで(超過分は記録しない)
- メールアドレス形式検証、電話番号は数字・ハイフンのみ許容
- ファイルアップロード: MIMEタイプ実体検証(マジックバイト)、8MB上限、画像以外拒否、変換後のみ保存

### 認証・権限
- Supabase Auth(メール+パスワード、パスワード最低10文字)
- 管理画面(/admin)はrole=admin/staffのみ。middleware+RLSの二重防御
- adminとstaffの分離: staffは削除・権限付与・統合・非公開化以外の閲覧/編集のみ
- セッションはSupabaseのデフォルト(自動更新)を使用
- 管理者アカウントは複数発行可能(運営継続性要件)

### インフラ・データ
- RLS全テーブル有効(DATABASE_SCHEMA.md 参照)
- SUPABASE_SERVICE_ROLE_KEY はサーバーのみ。クライアントバンドルへの混入をビルド時に検査
- 監査ログ: 全更新系操作を audit_logs へ記録。ログ自体は改変不可
- バックアップ: Supabaseの自動バックアップ(無料枠は7日、Pro移行で30日)。加えて週次でCSVエクスポートをStorageの非公開バケットへ保存するcronを用意
- エラー監視: Sentry連携。申込み通知メールの送信失敗は必ず捕捉し管理者へ通知
- 依存パッケージ: Dependabot有効化

## 2. 個人情報の取扱い

### 収集する個人情報
体験・見学申込み(氏名・メール・電話・自由記述)、運営者アカウント(メール)、通報の連絡先(任意)。それ以外の個人情報を収集しない。アクセス解析はcookieレスまたは匿名のもののみ。

### 保持と自動匿名化
- trial_applications は作成から **180日** で氏名・メール・電話・自由記述をNULL化(pg_cron日次)。統計情報(件数・地域・日時・見学/体験区分・状態)は保持
- phone_tap_events の session_hash はハッシュ値のみで個人特定不可。生cookie値を保存しない
- 運営者アカウントは退会申請で無効化し、profilesの表示名を削除

### アクセス制限
- 申込み個人情報の閲覧: 当該道場の管理権限を持つownerと、staff/adminのみ
- 個人情報を含むCSVエクスポートはadminのみ実行可能とし、監査ログに記録

### 子どもの保護
- 子ども同士・指導者と子どもが直接やり取りできる機能を作らない
- 申込みフォームは保護者または成人本人が送る前提の文言を明記(「未成年の方の体験・見学は、保護者の方がお申し込みください」)
- 子どもが写る写真は保護者等の同意を得たもののみ掲載する旨を、写真アップロード画面に常時表示
- 不適切な指導等に関する通報窓口(/contact)を設け、reports キューで管理

## 3. 法務ページ(フェーズ7で文面を作成し、リリース前に運営者が最終確認)

### 必須ページと要点
- **利用規約(/terms)**: サービスの性質(情報掲載プラットフォームであり、指導品質・安全性・所属関係を保証しない)、掲載情報の自己申告性、禁止事項(虚偽登録・なりすまし・対象外道場の登録・誹謗中傷)、掲載の修正・非公開化・削除の運営裁量、免責
- **プライバシーポリシー(/privacy)**: 個人情報保護法準拠。収集項目・利用目的(道場への取次・統計)・保持期間(180日で匿名化)・第三者提供(申込先道場への提供のみ)・開示等請求窓口
- **掲載基準(/guidelines)**: 対象は全空連系道場(自己申告制)、虚偽・なりすまし・不適切写真への対応、修正・削除依頼の方法
- **運営理念(/about)**: 情報格差の解消、収益の一部を空手普及活動(園・学童等へのチラシ、認知広告、初心者家庭への情報提供)へ還元する構想。押しつけがましい表現・厳しさの強調は避ける

### 表示上の注意(全ページ共通)
- フッターに「本サイトは全日本空手道連盟の公式サイトではありません」を常時表示
- 全空連のロゴ・マークを使用しない。名称は事実の説明(「全日本空手道連盟系の道場を掲載」)の範囲でのみ使用
- 所属情報の免責文(道場詳細ページ): 「掲載されている所属情報は、原則として各道場からの申告または公開情報に基づいています。当サイトが所属関係を保証するものではありません。」
- 費用の免責文: 「入会時に必要な費用、スポーツ保険、登録料、道着・防具代、審査料、大会参加費等については、見学・体験時に各道場へご確認ください。」
- 断定表現の禁止(CLAUDE.md「表現上の禁止事項」参照)
- 将来アフィリエイトを導入する場合の表示要件(景表法・ステマ規制): 「当サイトはアフィリエイト広告を利用しています」等の明示、PR表記、道場指定品・大会規格の確認喚起 — MVPでは対象ページが存在しないため実装不要だが、要件として記録しておく

## 4. 通報・修正・削除フロー

1. /contact または道場詳細の「掲載内容の修正・削除を依頼する」リンクから送信
2. reports に記録し、管理者へメール通知
3. 管理者が確認し、必要に応じて該当道場を即時非公開化(flag_status='reviewing')
4. 対応結果を handled_note に記録しクローズ

なりすまし編集の疑いがある場合: 該当ownerの dojo_managers を取消し→道場を非公開化→audit_logsで編集履歴を確認→復元。
