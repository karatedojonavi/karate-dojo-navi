# SEO・コンテンツ計画(SEO_CONTENT_PLAN)

## 1. 狙う検索クエリ

地域系: 「群馬県 空手道場」「前橋市 空手教室」「横浜市 全空連 空手」
属性系: 「子供 空手 習い事」「初心者 空手道場」「大人 空手 再開」「土曜日 空手教室」「月謝が安い 空手道場」
流派系: 「松濤館流 空手道場」「剛柔流 空手道場」「糸東流 空手道場」「和道流 空手道場」

地域×道場詳細ページを主戦場とし、属性系・流派系はトップ・ガイドページと検索結果ページの静的説明文で受ける。

## 2. URL構造

```
/                        トップ
/area/gunma              都道府県ページ(slugはローマ字)
/area/gunma/maebashi     市区町村ページ
/dojos/[uuid]            道場詳細
/search?pref=&city=&...  検索結果(noindex)
/guide /faq /about ...   コンテンツページ
```

- 道場詳細のURLはuuidベース(道場名変更でURLが壊れないため)。titleとh1で道場名を出す
- /search はクエリ組合せが無限のため noindex, follow。SEOは地域ページが担う

## 3. 地域ページの仕様

### 都道府県ページ(/area/[pref])
- h1: 「{都道府県}の空手道場・空手教室一覧」
- 冒頭文(テンプレート+変数): 「{都道府県}にある全日本空手道連盟系の空手道場・教室を{掲載数}件掲載しています。市区町村、稽古曜日、月会費、流派から探せます。」
- 掲載道場一覧(市区町村別にグループ化)
- 市区町村リンク一覧(**掲載道場が1件以上ある市区町村のみリンク生成**)
- 掲載0件の都道府県ページ: 「現在準備中です。道場運営者の方はこちらから無料掲載できます」の薄いページとし、noindexを付与。1件以上でindexに切替

### 市区町村ページ(/area/[pref]/[city])
- **掲載道場が0件の市区町村ページは生成しない**(リンクも張らない、sitemapにも載せない)。内容のないSEOページの大量生成を禁止
- h1: 「{市区町村}({都道府県})の空手道場・空手教室」
- 道場カード一覧+隣接市区町村への内部リンク(同県内の掲載ありの市区町村)

| ページ | title | description |

- canonical: 全ページ自己参照。/searchはトップをcanonicalにしない(noindexのみ)
- OGP: サイト共通画像(道場詳細は道場写真があればそれを使用)

## 5. 構造化データ(JSON-LD)

- 道場詳細: `SportsActivityLocation`(name, address(主たる稽古場所), telephone(電話受付可の場合), url, image)+`BreadcrumbList`
- 地域ページ: `BreadcrumbList` + `ItemList`(掲載道場)
- FAQページ: `FAQPage`
- レビュー・評価系の構造化データは使用しない(口コミ機能がないため)

## 6. サイトマップ・クロール制御

- app/sitemap.ts で動的生成: トップ、コンテンツページ、掲載1件以上の地域ページ、公開中の道場詳細
- robots.ts: /owner, /admin, /api をDisallow。/searchはmetaのnoindexで制御
- 道場情報更新時: 該当道場詳細と所属地域ページを revalidate(ISR: revalidateTag または path)。地域ページはrevalidate間隔24時間+更新時即時
- パンくず: トップ > {県} > {市区町村} > {道場名}

## 7. パフォーマンス

- 画像はnext/imageで配信(WebP・サイズ最適化済み)
- 地域ページ・道場詳細はISRで静的配信
- Core Web Vitals: モバイルでLCP 2.5秒以内を目標。フェーズ6でLighthouse計測を完了条件に含める
